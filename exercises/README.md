# Учебные практические задания (Exercises Archive)

В этом каталоге сохранены учебные лабораторные работы и практические задания, выполненные на ранних этапах курса до перехода к основному архитектурному проекту аналитики продаж (`sales`):

1. **`script_calculator/`** (`script.py`, `test.py`): ранние эксперименты с функциями деления, вычитания и ручными проверками через `assert`.
2. **`make_capp/`** (`makeutil/capp`): практическое задание по основам GNU Make и компиляции C-программ (`gcc`).
3. **`testing_principles/`** (`testing/principle`): демонстрация базовых принципов тестирования (кластеры эквивалентности, парадокс пестицида, коммутативность).
4. **`testing_tdd/`** (`testing/tdd`): практика разработки через тестирование (TDD) на примере расчета прогрессивной шкалы налога (НДФЛ).
5. **`microservices_templates/`** (`order_service`, `product_service`, `PracticeMakefile`): заготовки структуры микросервисов и шаблон Makefile для генерации новых практик.

*Основной инженерный проект курса расположен в корневом каталоге (`src/sales`, `app/`, `tests/`, `docs/`).*
